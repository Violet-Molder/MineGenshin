# 飞行与下落攻击

## 这个系统负责什么

「二连跳起飞 → 前摇 → 自由飞行」这一整套，以及落到地上那一下（**下落攻击**）与**摔落伤害**。
飞行本身用的是**原版创造飞行**（`abilities.flying`），本模组负责的是：怎么进入、进入前播什么、
飞行期间能做什么不能做什么、代价是什么、以及落地怎么结算。

## 进入飞行：二连跳 → 前摇 → `flying = true`

1. **二连跳**沿用原版那套创造飞行开关（双击跳跃）。原神模式下模组让 `mayFly()` 为真，
   所以这一套本来就能用；**生存模式需要背上有滑翔装备**（鞘翅这类，走 NeoForge 的
   `GLIDING_FLIGHT` 判定），创造 / 旁观不需要。
2. 检测到「刚把飞行打开」之后**不立刻起飞**，先播一段**前摇动画**
   （`SkillBase#flyStartAnimation()`，林薇云按武器形态给 `fly_start_<形态>`；时长
   `SkillBase#flyStartTicks()`，林薇云按形态查表）。
   - 前摇期间**已经是飞行状态**（悬停、微微离地、不会落地 —— 落地会被原版关掉飞行）；
   - 前摇期间**锁死全部移动输入**，并且每刻清掉水平惯性（稳稳悬在起手那一点）；
   - 前摇走完只是解开锁 + 收掉动画状态，飞行状态一路保持。
3. **前摇被打断**：被别的动作顶掉（例如按普攻 → 下落攻击）才会作废，要飞得再跳一次。

> 前摇刻数**必须 ≥ 素材长度**，否则动画没播完就被飞行动画接走。

## 飞行期间的三条规矩

| 规矩 | 落在哪 |
| --- | --- |
| 不能更换队伍角色 | 客户端拦 V 键；服务端 `NetworkManager#characterSelectionRPCPacket` 也拒 |
| 不能放技能 / 大招 | **写在技能基类**（`SkillBase#canCast`，`PGCharacter#canCast` 与客户端 `ActionCastGuard` 共用同一条规则），不是拦按键 —— 部分角色的部分技能本来就允许空中放，那种角色覆盖基类即可 |
| 普攻 = 下落攻击 | 飞行中按左键直接关掉飞行扎下去，落地结算（见下） |

## 代价：滑翔装备 × 耐久

原版滑翔是每 20 刻扣 1 点耐久；自由飞行按 `20 / 倍率` 刻扣 1 点，倍率在
`config/minegenshin/gameplay.toml` 的 `flight.elytra-durability-multiplier`（默认 **2.5** →
每 8 刻 1 点）。**没有滑翔装备就停飞**，飞着的时候装备碎了 / 被拿走也立刻停飞。

## 飞行片段：按形态分，水平档再细分

- `CharacterAnimations#locomotionFor(Player)` 让「按角色现状挑常态动画」成为可能
  （`LocomotionAnims` 存的是固定名字、拿不到玩家）。林薇云按当前武器形态给：
  拳 → `fly`、剑 → `fly_sword`、长柄 → 长柄那一组、大剑 → `fly_claymore`、
  法器 → `fly_catalyst`、弓 → `fly_bow`。
- 上升 / 下降 / 水平是三档；水平档内部还能再细分 —— 由
  `CharacterAnimations#flyVariant(player, loco, moving)` 决定（林薇云长柄：疾跑 → 冲刺、
  有水平移动 → 往前、都不动 → 悬停）。
- **升降看按键，不看速度**：飞行时松开空格后人还会带着惯性继续往上飘，用竖直速度判断
  会晚一拍（旧问题是「停下来还要等近一秒才恢复」）。
- **本地玩家选中哪条片段，走现成的动画状态包广播出去**（`sendAnimationStateToServer`
  → `ServerAnimationTicker` → 别的客户端的动画状态附件），远端照播，不再自己按位移猜。
- **重进存档时要跟 `abilities.flying` 对齐一次**：存档里飞行是恢复的，而客户端那份镜像
  从零开始，不对齐就会被误判成「刚打开飞行」又补一次前摇。

## 武器脱手：放飞骨骼

坐骑式飞行（长柄当扫帚）时武器不能跟着手走：模型里除了手骨 `long`，另有一根
**挂在身上的 `polearm_fly`**（几何是复制的一份，挂点也指向同一个武器槽）。

- 常态藏 `polearm_fly`、显示手骨；**飞行时反过来**（`CharacterAppearanceData#flightBones`
  + `CharacterAppearanceOptionBones` 的飞行分支）；
- **起飞前摇期间只藏手骨**，放飞骨骼的显隐交给动画自己（素材里用 `scale` 排了
  「先脱手、再出现」的时间线）；
- 骨骼的父子关系烘培时定死，运行期改不了 —— 所以只能「复制一根 + 切显隐」。

## 下落攻击（落地那一下）

招式本体写在技能里：`SkillBase#plungingAttack(player, character)`，和 `attack` / `chargeAttack`
同一处；基类实现是「落地时对身周 3 格打一发 `AttackType.PLUNGING_ATTACK`」，
**所有角色都自带**，有自己花样的角色覆盖即可。

- 触发：坠落中（离地、`fallDistance > 2`）按普攻；**飞行中按普攻同样触发**；
- 触发后把垂直速度压到加速下坠值、**不重置** `fallDistance`（摔伤按总高度算）；
- 落地检测在服务端（`CharacterTickHandler#tickPlungeAttack`），不等客户端报落地；
- 状态与锁输入见 `PlungeState`（键带 `C:`/`S:` 前缀，和 `ActionManager` 同一套）。

**为什么不做成 `ActionSet` 里的一格**：下落攻击不是固定时长的动作，它从按下持续到落地，
`ActionStep` 那套「第几刻出伤害」表达不了。

## 摔落伤害：按最大生命值的百分比

原版是「(高度 − 安全高度) × 1 点血」，和角色的血量不是一个量纲。现在按用户的表来
（`FallDamage`，两点之间线性插值）：

| 高度(格) | 12 | 14 | 16 | 18 | 20 | 21 | 22 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 剩余(%) | 100 | 78.7 | 62.0 | 32.6 | 22.9 | 13.1 | 0 |

下落攻击会把**免伤区间抬到 38 格**：38 → 40 线性到扣 10%，40 → 50 到扣满。
拦截点在 `Player#causeFallDamage`（`PlayerFallDamageMixin`）：玩家入口 HEAD 取消，
整条原版链都不跑；「能飞就不吃摔伤」「被爆炸 / 风弹顶起来那一摔不算」照旧放行给原版；
方块自带的减免（粘液块 0.0 / 干草 0.2 / 石笋 2.0）照乘在这个百分比上。

## 加一个新角色 / 新形态

1. 角色技能继承 `SkillBase`，按需覆盖 `plungingAttack` / `flyStartAnimation` /
   `flyStartTicks` / `canCast`；
2. 形态化的飞行片段在 `CharacterAnimations#locomotionFor` 与 `#flyVariant` 里给；
3. 需要「武器脱手」时，模型里复制一根挂在身上 / 胯上的骨骼，并在
   `CharacterAppearanceData#flightBones` 里给出「手骨 → 放飞骨骼」的映射。

## 常见坑

| 现象 | 原因 |
| --- | --- |
| 前摇期间「飞不起来」 | 前摇里把飞行压回 false，一跳的滞空不够长就落地，而原版 `onGround && flying` 会关掉飞行 |
| 前摇期间武器变成两把 | 外观 updater 只在 `default` 状态干活，前摇是动作状态 → 要单独给「前摇档」的显隐 |
| 升降切换慢半拍 | 用竖直速度判断升降；飞行有惯性，松手后速度还在 |
| 重进存档 / 切第三人称突然播一次起飞 | 客户端飞行镜像没跟存档里的 `abilities.flying` 对齐 |
| 长柄飞行时武器跟着手跑 | 武器骨骼是手的子节点，动画只能在手坐标系里挪 —— 必须另做放飞骨骼 |
